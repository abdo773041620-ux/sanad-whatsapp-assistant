# سجل المصادر والأدوات وحقوق الاستخدام

## المصادر المحددة في البحث

| النطاق | الاستخدام في التعليمات |
|---|---|
| dawa.center | التعريف بالإسلام ومواد تعليمية، مع أولوية ملف بينات 7937 عند ملاءمته |
| islamic-content.com | المصطلحات والمحتوى الإسلامي، مع أولوية القاموس |
| quranpedia.net | النص القرآني ومعانيه مع التحقق من النسبة |
| dorar.net | الحديث والتفسير والعقيدة والفقه والتاريخ بحسب السؤال |
| shamela.ws | نصوص الكتب مع فحص النسبة والإصدار والدليل المتاح |

هذه قائمة نطاقات البحث، وليست ترخيصاً بإعادة نشر كل محتوياتها أو اعتماداً تلقائياً لكل صفحة. لا يحوي المستودع نسخة محلية من تلك المكتبات. تُسترجع المواد وقت السؤال؛ تراعى حقوق الناشر وشروط المصدر عند الاستخدام أو الاقتباس.

## الأدوات والمكونات

| المكوّن | الوظيفة | الحقوق والاعتمادات |
|---|---|---|
| n8n | تشغيل الوركفلو | منتج خارجي؛ راجع شروط وترخيص نسختك لدى n8n |
| Google Gemini | النموذج اللغوي | API خارجي يخضع لشروط Google وحساب المشغّل |
| Tavily | البحث والاستخراج | API خارجي يخضع لشروط Tavily وحصص الحساب |
| Meta WhatsApp Cloud API | استقبال وإرسال الرسائل | خدمة خارجية تخضع لشروط Meta وسياسات واتساب |
| خط واجهة سَنَد | ملف WOFF ضمن web/fonts | نص الترخيص المرفق في web/fonts/OFL.txt |

ملفات الوركفلو والتعليمات وواجهة المشروع منشورة للاطلاع والتوثيق. لم يحدد صاحب المشروع بعد ترخيصاً مفتوحاً عاماً لبقية كود المشروع؛ الإتاحة العامة وحدها لا تعني منح جميع حقوق إعادة الاستخدام. لا يضم المستودع أسرار حسابات أو محتوى محادثات المستخدمين.

## فصل المنجز عن السابق

سبقت التحدي أعمال إعداد ربط الخدمات وحسابات Meta وn8n. توضح ملفات المشروع النسخة الحالية؛ لا يمثل سجل GitHub الجديد تاريخاً كاملاً لكل التطوير السابق. تطورت خلال العمل تعليمات الاستناد والامتناع واللغة، وأداة البحث، وتجربة الويب، والتوثيق. لا توجد دراسة معيارية تثبت تحسناً رقمياً في الدقة أو الزمن.
